## Deleting GitHub Repositories Programmatically

Below are two straightforward ways to delete a GitHub repository from a script or the command line. Pick the approach that best fits your workflow.

---

### 1️⃣ Python + GitHub REST API (recommended for automation)

```python
#!/usr/bin/env python3
"""
Delete a GitHub repository using the REST API.

Prerequisites:
  • Python 3.8+
  • `requests` library (`pip install requests`)
  • A **personal access token** (PAT) with the `delete_repo` scope.
"""

import os
import sys
import requests
from urllib.parse import quote_plus

API_URL = "https://api.github.com"
TOKEN_ENV = "GITHUB_TOKEN"   # name of the env‑var that holds the PAT


def delete_repo(owner: str, repo: str, token: str) -> None:
    """Send a DELETE request to remove the repo."""
    url = f"{API_URL}/repos/{quote_plus(owner)}/{quote_plus(repo)}"
    headers = {"Authorization": f"token {token}", "Accept": "application/vnd.github.v3+json"}
    resp = requests.delete(url, headers=headers)

    if resp.status_code == 204:
        print(f"✅ Repository {owner}/{repo} deleted successfully.")
    else:
        print(f"❌ Failed to delete repo (status={resp.status_code})")
        try:
            print("Response:", resp.json())
        except Exception:
            print(resp.text)
        sys.exit(1)


def main() -> None:
    if len(sys.argv) != 3:
        print("Usage: delete_repo.py <owner> <repo>")
        sys.exit(1)

    owner, repo = sys.argv[1], sys.argv[2]
    token = os.getenv(TOKEN_ENV)

    if not token:
        print(f"⚠️  Set the environment variable {TOKEN_ENV} with a PAT that has `delete_repo` permission.")
        sys.exit(1)

    # Safety check – confirm before deleting
    confirm = input(f"Are you *absolutely sure* you want to delete {owner}/{repo}? (type 'YES' to proceed): ")
    if confirm != "YES":
        print("Aborted.")
        sys.exit(0)

    delete_repo(owner, repo, token)


if __name__ == "__main__":
    main()
```

#### How to use
1. **Create a PAT**  
   - Go to **Settings → Developer settings → Personal access tokens**.  
   - Generate a new token with **`delete_repo`** (and optionally `repo` for other operations).  
   - Save the token securely.

2. **Export the token** (one‑time per session):
   ```bash
   export GITHUB_TOKEN=ghp_XXXXXXXXXXXXXXXXXXXXXXXXXXXX
   ```

3. **Run the script**
   ```bash
   python3 delete_repo.py <owner> <repo>
   ```
   Replace `<owner>` with your GitHub username or organization, and `<repo>` with the repository name.

> **⚠️ Caution** – Deleting a repo is irreversible. The script asks for an explicit `YES` confirmation to avoid accidental loss.

---

### 2️⃣ GitHub CLI (`gh`) – one‑liner

If you already have the **GitHub CLI** installed, you can delete a repo with a single command:

```bash
# Install gh if needed (macOS)
brew install gh

# Authenticate (once)
gh auth login   # choose HTTPS and follow prompts

# Delete the repo (you’ll be prompted to confirm)
gh repo delete <owner>/<repo> --confirm
```

Add `--yes` to skip the prompt (use with extreme care):

```bash
gh repo delete <owner>/<repo> --yes
```

---

## Choosing Between the Two

| Feature                     | Python script | `gh` CLI |
|-----------------------------|---------------|----------|
| ✔️ Full automation (e.g., in CI/CD) | ✅ | ❌ (requires interactive login) |
| ✔️ Single‑command usage            | ❌ | ✅ |
| ✍️ Custom logging / error handling | ✅ | ❌ |
| ✅ No extra dependencies (just `gh`) | ❌ (needs `requests`) | ✅ |

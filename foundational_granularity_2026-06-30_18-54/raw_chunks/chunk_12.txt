### 1. Centralized Storage & Immutability Strategy (The Compiled Gate Law)
To resolve the historical challenge of scattered, vulnerable Python scripts, I have codified the following storage and execution structure:
*   **Central Storage Directory**: All deterministic validation, orchestration, and check utilities live in a centralized, read-only control centre directory: `/Users/ewansair/control-centre/bin/` (or `/opt/amplified/bin/` on the primary `[Beast]` server).
*   **Immutability Protection**: Core security gates (such as the Outbound Doorway runner, the write gate, and the cross-verifier) must be compiled in **Rust** and run as static binaries rather than editable Python scripts. This prevents executing AI agents from mutating the validation code in-flight to bypass checks.
*   **Harness Registry**: All active scripts and binaries are cataloged in `ESTATE-TAXONOMY.md` and the `ai_orientation_guide` database table for automatic discovery.
